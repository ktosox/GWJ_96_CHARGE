# GWJ_96_CHARGE

Update - about 10 hours before the deadline I've decided to tap out.
But I would like to see this finished, so hopefully I'll find a couple hours over the week to make a working prototype.

Of all the core things I didn't finish, I think cards and combat are the biggest reasons I decided to give up.

Kinda silly, a card game without any cards...
